# battery-health-prediction
AI-based Battery Health Prediction and Monitoring System using Machine Learning
this project uses machine learning to predict battery state of health (SOH) and remaining useful life (RUL) using NASA battery degradation data.
##features
battery health prediction
SOH Estimation
RUL Prediction
Data Visualization
Machine Learning Model
##Technologies used
python
google colab
pandas
numpy
scikit_learn
matplotlib
##Dataset
NASA Degradation dataset
